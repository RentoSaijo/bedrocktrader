# List Supported Minecraft Bedrock Versions

Retrieves Mojang's stable-version registry and lists releases at or
above the minimum version supported by `bedrocktrader`.

## Usage

``` r
bedrock_versions()
```

## Value

A base data frame containing stable version identifiers, release dates,
and an indicator for Mojang's current latest stable release.

## Examples

``` r
if (FALSE) { # \dontrun{
bedrock_versions()
} # }
```
